Le mod visuel qui donne de l'éclat à Minecraft.

NEBULA est un mod 100 % côté client : interface rendue par le GPU, orbes 3D émissives, traînées de mouvement, HUD déplaçable et un ClickGUI entièrement configurable.

Fonctionnalités

Pensé pour être beau, fluide et à votre goût

Chaque effet est réglable : style, couleurs, animation, bloom, densité, taille, vitesse, durée et intensité.

Interface rendue par le GPU

Panneaux en verre dépoli, animations douces et transparence réglable, sans sacrifier les performances.

Orbes 3D émissives

Des sphères lumineuses gravitent autour de votre personnage, avec halo et bloom.

Traînées de mouvement

Un ruban de lumière animé suit chacun de vos déplacements.

HUD déplaçable

Filigrane, coordonnées, horloge et liste des modules : placez chaque élément où vous voulez.

ClickGUI configurable

Recherche, catégories, raccourcis par module, curseurs au clavier et sélecteur de couleurs.

Thèmes personnalisables

Partez d'un preset puis modifiez chaque couleur de l'interface avec le Theme Editor.

Installation

Prêt en trois étapes

  1. 01

    Installez Fabric

    Fabric Loader ≥ 0.20.1 et Fabric API 0.141.x+1.21.11 pour Minecraft 1.21.11.

  2. 02

    Ajoutez le mod

    Placez nebula-1.0.0.jar dans le dossier .minecraft/mods.

  3. 03

    Lancez le jeu

    Appuyez sur Shift droit pour ouvrir le ClickGUI.

Compiler depuis les sources

Compilez avec Java 25 (cible Java 21, Loom 1.19, Gradle 9.8.2). Le jar est généré dans build/libs/nebula-1.0.0.jar.

git clone https://github.com/c2server-hub/nebula-client.git
cd nebula-client
./gradlew build

Commandes

Prise en main rapide

Shift droit

Ouvre le ClickGUI (touche modifiable).

Clic gauche / droit

Active un module / ouvre ses réglages.

← →

Ajustent le curseur survolé.

Recherche

Filtre les modules par nom.

HUD Layout

Repositionne les éléments du HUD.

Save / Reset

Double-clic pour confirmer.
