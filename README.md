# Nebula-site

Site vitrine statique pour [NEBULA Client](https://github.com/c2server-hub/nebula-client), un mod visuel côté client pour Minecraft 1.21.11 (Fabric).

HTML, CSS et JavaScript sans dépendance ni étape de build. Les captures dans `assets/img` proviennent de `docs/screenshots` du dépôt du client, converties en WebP.

## Lancer en local

```sh
python3 -m http.server 8080
```

Puis ouvrir http://localhost:8080.

## Publier

Compatible GitHub Pages : activer Pages sur la branche voulue, dossier racine.
